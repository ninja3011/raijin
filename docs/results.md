# Raijin results

> The SRAM rework (Q/K/V/O and the score buffer in four sky130 SRAM macros,
> registered bus, KV-cache decode mode) is described with its layout numbers in
> `docs/sram_kv.md`. The tables below are for the original flip-flop design.

All numbers are for N = d = 16, one head, MXINT8 inputs, 50 MHz target.

## Cycles per attention pass (RTL simulation, measured by the CYCLES counter)

| Dataflow | Cycles | Time at 50 MHz | Score storage |
| --- | --- | --- | --- |
| Unfused | 369 | 7.38 µs | 16 × 16 × 12 bits in the score buffer |
| Fused | 169 | 3.38 µs | none |

The fused dataflow is 2.18× faster on the same blocks. Both read the same
inputs; outputs differ only by the rescale truncation of the online softmax.

## Accuracy

See `results/accuracy.md` (generated by `model/accuracy.py`). Mean cosine
similarity against FP32 attention, fused dataflow:

| Variant | gauss | gauss_sharp | llm_outliers |
| --- | --- | --- | --- |
| Exact (LUT exp, 9×8 multipliers) | 0.99983 | 0.99978 | 0.99981 |
| Multiplier-free, one power of two | 0.98639 | 0.99639 | 0.99051 |
| Multiplier-free, two powers of two | 0.99854 | 0.99947 | 0.99872 |

Underflow skipping is exact: every skipped update had p = 0. On the sharp
random case the unfused pass skips 182 of 256 updates and the fused pass 138.

## sky130 (OpenLane 2 / LibreLane)

Hardened configuration: `openlane/config_p2.json`, the spec's fallback with
P = 2 DPUs and softmax lanes (713 cycles unfused, 317 fused, still bit-exact).
The 4-DPU layout routed globally but did not converge in detailed routing
(about 126k metal-1 shorts after three passes, with the router using all of
the 10 GB available to WSL). Full metrics: `results/openlane_summary.md`.

| Metric | P = 2 |
| --- | --- |
| Die | 2.209 × 2.220 mm (4.90 mm²) |
| Standard-cell area | 1.94 mm² (40% of the core) |
| Flip-flops | 14,824 |
| Setup slack at 50 MHz, typical / fast / slow corner | +2.38 / +8.92 / −14.1 ns |
| fmax, typical corner | about 56 MHz |
| fmax, slow corner (100 °C, 1.60 V) | about 29 MHz |
| Hold, typical and fast corners | met (reg-to-reg hold is met at every corner) |
| Total power, typical corner, default activity | 87 mW |
| Detailed-route DRC / Magic DRC | 0 / 0 |
| Antenna-violating nets after diode insertion | 58 |

Resizing was run for the typical and fast corners only, so the slow corner is
reported, not repaired. The hold violations OpenSTA lists at the slow corner
are on input-port paths, which a wrapper with registered I/O would remove.
